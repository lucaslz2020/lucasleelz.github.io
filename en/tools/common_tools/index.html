Common Development Tools

An overview of development tools like nrm and Multipass — what they do, how to install them, and the commands you'll use most.

nrm

nrm is a handy tool for managing npm registry mirrors. It makes it quick and easy to switch between different npm mirrors.

Why use nrm?

  1. Some npm packages are frequently unreachable on a given mirror, so npm dependencies can’t be downloaded. (nrm lets you switch npm sources quickly.)
  2. The common mirrors are built in, so there’s no need to add them manually.
  3. Many companies run private npm mirrors, and nrm makes adding and using them easy.

How to use it?

Install

npm install -g nrm

Check the installed version

This step is a quick way to verify that nrm is installed correctly.

nrm --version

Result: 1.2.5

Uninstall

npm uninstall -g nrm

List all mirrors

nrm ls

Result:

* npm ---------- https://registry.npmjs.org/
  yarn --------- https://registry.yarnpkg.com/
  tencent ------ https://mirrors.cloud.tencent.com/npm/
  cnpm --------- https://r.cnpmjs.org/
  taobao ------- https://registry.npmmirror.com/
  npmMirror ---- https://skimdb.npmjs.com/registry/

The * marks the mirror currently in use.

Add a private registry

add <registry> <url> [home] Add one custom registry
nrm add private_registry http://192.168.1.20:4873/

Use the added private registry

use <registry>  Change registry to registry
nrm use private_registry

Test mirror speed

test [registry] Show response time for specific or all registries
# 测试全部
nrm test
# 测试指定镜像
nrm test private_registry

Help

The help manual explains each command in detail.

nrm --help

multipass

A lightweight Ubuntu virtual machine that can only virtualize Ubuntu.

Supports Linux, Windows, and macOS.

Why use Multipass?

  1. It’s easy to spin up an Ubuntu VM.
  2. It’s especially well suited to learning Ubuntu.

How to use it?

Install

brew install --cask multipass

Check the installed version

multipass version

Multipass app

After installation, a Multipass app appears on your desktop, letting you manage instances from a GUI.

Uninstall

brew uninstall multipass

List all images

multipass find

Launch an instance

multipass launch --name foo

List all instances

multipass list

Delete an instance

multipass delete foo

Purge all deleted instances

multipass purge

Help

multipass help

CSS Float

Understand the behavior of float and clear, along with caveats and common practices, starting from the original purpose of float.

May 28, 2022 2 min read
#CSS

float shows up in web layouts all the time, but it wasn’t designed for today’s mainstream layouts. Understanding its mechanics is the key to avoiding common compatibility and height-collapse issues.

Float

What Is Float?

When an element is floated, other content flows around it.

A floated element is taken out of the normal document flow, but it still affects the layout.

Why Use Float?

Newspapers and magazines typically have images surrounded by text. This is exactly the scenario float is designed for.

The float API

A floated element floats relative to its parent element.

Name: float
Value: left | right | none | inherit
Initial: none

left

A floated element automatically gets display:block and floats to the left.

right

A floated element automatically gets display:block and floats to the right.

Notes

No matter what the element is, it gets a display:block block-level box after being floated. There is therefore no need to manually declare display:block.
Multiple floated elements do not overlap
If a floated element is taller than its parent, it affects the elements that follow it
A floated element can float onto negative margins, making it look wider than its parent
If a floated element overlaps content, the content always renders on top of the floated element.
  • Inline elements: border, background, and content all render on top of the floated element.
  • Block-level elements: border and background render below the floated element, while content renders on top of it.

Clearing Floats

Clearing floats prevents content from flowing around a floated element.

The clear API

Name: clear
Value: none | left | right | both | inherit
Initial: none

left

The left side stays clear of floated elements.

right

The right side stays clear of floated elements.

both

Both sides stay clear of floated elements.

Notes

clear works by increasing the element’s top margin (marginTop). Since you often do not know how far down the element needs to move, the common workaround is to add a bottom margin to the floated element.

In Practice

If you want a left–right layout, you can simply use float: right.

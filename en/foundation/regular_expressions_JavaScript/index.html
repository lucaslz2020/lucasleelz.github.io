Using Regular Expressions in JavaScript

Practice creating, matching, and processing regular expressions with JavaScript's RegExp and String APIs.

Practice with JavaScript.

In JavaScript, regular expressions are objects too. They are commonly used with APIs such as RegExp’s exec and test, and String’s match, replace, and search.

There is rarely a single final answer for a regular expression. More often, the right choice depends on your tolerance for uncertainty, and multiple solutions can work at the same time.

Creating a Regular Expression

Literal syntax

The pattern is written between two slashes //.

/[0-9]/

RegExp

Call the RegExp constructor.

new RegExp("[0-9]")

Flags

FlagDescription
gGlobal search
iCase-insensitive search
mMultiline search

/pattern/flags或 new RegExp("pattern", "flags")

Common Regular Expressions

Matching phone numbers

Phone number prefixes change frequently as new ranges are released, so there’s no need to restrict them too tightly.

Start with 1, followed by 10 digits, for an 11-digit phone number.

const PHONE_NUMBER_REGEXP = /^1\d{10}$/;

export const isPhoneNumber = (phoneNumber?: string) => {
  if (!phoneNumber) {
    return false;
  }
  return PHONE_NUMBER_REGEXP.test(phoneNumber);
};

Validating an ID card number

  1. It has 18 digits.

  2. The first 6 digits are the region code, with the first digit ranging from 1 to 8.

  3. The next 8 digits are the date of birth.

  4. The following 3 digits are the sequence code.

  5. The last digit is the checksum (a number or X).

Simple version

/[1-8]\d{16}[0-9X]/i

Strict version

RegexDescription
[1-8]\d{5}First 6 digits
[1|2]\d{3}Year
[01]\dMonth
[0-3]\d{4}Day + 3-digit sequence code
(\d|x)Last digit is the checksum
const ID_CARD_REGEXP = /^[1-8]\d{5}[1-2]\d{3}[01]\d[0-3]\d{4}(\d|X)$/i;

export const isIDCard = (IDCard?: string) => {
  if (!IDCard) {
    return false;
  }
  return ID_CARD_REGEXP.test(IDCard);
};

Matching email addresses

Simple version

/^\w+@\w+\.\w+/i

A pattern like this won’t match an address such as aa.aa@aa.com.

Strict version

const EMAIL_NUMBER_REGEXP = /^(\w+\.)*\w+@(\w+\.)+[A-Za-z]+/i;

export const isEmail = (email?: string) => {
  if (!email) {
    return false;
  }
  return EMAIL_NUMBER_REGEXP.test(email);
};

Matching IP addresses

Simple version

/(\d{1,3}\.){3}\d{1,3}/i

Strict version

const IP_REGEXP =
  /^(((\d{1,2})|(1\d{2})|(2[0-4]\d)|(25[0-5]))\.){3}((\d{1,2})|(1\d{2})|(2[0-4]\d)|(25[0-5]))$/;

export const isIP = (IP?: string) => {
  if (!IP) {
    return false;
  }
  return IP_REGEXP.test(IP);
};

Matching URLs

Simple version

/^https?:\/\/[-\w.]+(:\d+)?(\/([\w\/_.]*)?)?$/i

Strict version

const URL_REGEXP =
  /^https?:\/\/(\w*:\w*@)?[-\w.]+(:\d+)?(\/([\w\/_.]*(\?\S+)?)?)?$/i;

export const isURL = (URL?: string) => {
  if (!URL) {
    return false;
  }
  return URL_REGEXP.test(URL);
};

Matching Chinese characters

const CHINESE_REGEXP = /^[\u4e00-\u9fa5]*$/;

export const isOnlyChinese = (chinese?: string) => {
  if (!chinese) {
    return false;
  }
  return CHINESE_REGEXP.test(chinese);
};

CSS 浮動

從浮動的原始用途出發，理解 float、clear 的行為、注意事項與常見做法。

很多時候我們會在 Web 版面中看到 float，但它的設計初衷並非針對當代主流版面。理解它的機制，才能避免常見的相容性與高度塌陷問題。

浮動

什麼是浮動？

如果把某個元素設為浮動，其他內容就會圍繞這個元素流動。

浮動元素會脫離正常的文件流，但仍然會影響版面。

為什麼要使用浮動？

現實中的報刊，都會有圖片被文字圍繞。這種情境就特別適合使用浮動。

浮動 API

浮動元素會相對於父級元素浮動。

Name: float
Value: left | right | none | inherit
Initial: none

left

浮動元素會自動獲得 display:block 屬性，並浮動到左邊。

right

浮動元素會自動獲得 display:block 屬性，並浮動到右邊。

注意點

不管是什麼元素，浮動後都會得到 display:block 區塊級盒子，因此不需要手動宣告 display:block。
多個浮動元素不會重疊
如果浮動元素比父級元素還高，會影響它後面的元素
浮動元素會浮到負外邊距上，看起來比父元素更寬
如果浮動元素與內容重疊，內容都會渲染在浮動元素之上。
  • 行內元素：邊框、背景、內容都會渲染在浮動元素之上。
  • 區塊級元素：邊框、背景渲染在浮動元素之下，內容渲染在浮動元素之上。

清除浮動

清除浮動是為了不讓內容跟著浮動元素流動。

清除浮動 API

Name: clear
Value: none | left | right | both | inherit
Initial: none

left

左邊遠離浮動元素

right

右邊遠離浮動元素

both

左右兩邊都遠離浮動元素

注意點

clear 的原理是增加元素的上外邊距（margin-top），但很多時候我們不知道元素需要下移多少，因此常見做法是在浮動元素上加下外邊距。

實作

想要實現左右版面，只要簡單使用 float: right 就可以了。

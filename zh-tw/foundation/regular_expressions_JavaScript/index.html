正規表達式在 JavaScript 中的實踐

使用 JavaScript 的 RegExp 與 String API 練習正規表達式的建立、比對與處理。

本文會使用 JavaScript 進行實際練習。

在 JavaScript 中，正規表達式也是物件，通常搭配 RegExp 的 exec、test 以及 String 的 match、replace、search 等 API 使用。

正規表達式很少存在唯一的最終方案，更多時候取決於你對不確定性的容忍程度；同一個問題往往不只有一種解法。

建立正規表達式

字面值的方式

把模式寫在兩條斜線 // 之間。

/[0-9]/

RegExp

呼叫 RegExp 物件的建構函式。

new RegExp("[0-9]")

旗標

旗標描述
g全域搜尋
i不區分大小寫搜尋
m多行搜尋

/pattern/flags 或 new RegExp("pattern", "flags")。

常用正規表達式

比對手機號碼

因為手機號段經常更新、持續釋出新號段，所以不必限制得太嚴格。

以 1 開頭，後面再接 10 位數字，即可組成 11 位手機號碼。

const PHONE_NUMBER_REGEXP = /^1\d{10}$/;

export const isPhoneNumber = (phoneNumber?: string) => {
  if (!phoneNumber) {
    return false;
  }
  return PHONE_NUMBER_REGEXP.test(phoneNumber);
};

驗證身分證字號

  1. 身分證字號共有 18 位。
  2. 前 6 位是地區代碼，其中第一位取值在 1～8。
  3. 接下來的 8 位是出生年月日。
  4. 接下來的 3 位是順序碼。
  5. 最後一位是檢查碼（數字或 X）。

簡單版

/[1-8]\d{16}[0-9X]/i

嚴格版

正規表達式說明
[1-8]\d{5}前 6 位
[1|2]\d{3}年
[01]\d月
[0-3]\d{4}日 + 3 位順序碼
(\d|x)最後一位是檢查碼
const ID_CARD_REGEXP = /^[1-8]\d{5}[1-2]\d{3}[01]\d[0-3]\d{4}(\d|X)$/i;

export const isIDCard = (IDCard?: string) => {
  if (!IDCard) {
    return false;
  }
  return ID_CARD_REGEXP.test(IDCard);
};

比對電子郵件信箱

簡單版

/^\w+@\w+\.\w+/i

如果電子郵件是 aa.aa@aa.com 這種格式，就比對不到了。

嚴格版

const EMAIL_NUMBER_REGEXP = /^(\w+\.)*\w+@(\w+\.)+[A-Za-z]+/i;

export const isEmail = (email?: string) => {
  if (!email) {
    return false;
  }
  return EMAIL_NUMBER_REGEXP.test(email);
};

比對 IP 位址

簡單版

/(\d{1,3}\.){3}\d{1,3}/i

嚴格版

const IP_REGEXP =
  /^(((\d{1,2})|(1\d{2})|(2[0-4]\d)|(25[0-5]))\.){3}((\d{1,2})|(1\d{2})|(2[0-4]\d)|(25[0-5]))$/;

export const isIP = (IP?: string) => {
  if (!IP) {
    return false;
  }
  return IP_REGEXP.test(IP);
};

比對 URL 位址

簡單版

/^https?:\/\/[-\w.]+(:\d+)?(\/([\w\/_.]*)?)?$/i

嚴格版

const URL_REGEXP =
  /^https?:\/\/(\w*:\w*@)?[-\w.]+(:\d+)?(\/([\w\/_.]*(\?\S+)?)?)?$/i;

export const isURL = (URL?: string) => {
  if (!URL) {
    return false;
  }
  return URL_REGEXP.test(URL);
};

比對中文字

const CHINESE_REGEXP = /^[\u4e00-\u9fa5]*$/;

export const isOnlyChinese = (chinese?: string) => {
  if (!chinese) {
    return false;
  }
  return CHINESE_REGEXP.test(chinese);
};

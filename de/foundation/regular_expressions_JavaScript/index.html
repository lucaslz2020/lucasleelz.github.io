Reguläre Ausdrücke mit JavaScript in der Praxis

Übungen zum Erstellen, Abgleichen und Verarbeiten regulärer Ausdrücke mit den RegExp- und String-APIs von JavaScript.

In diesem Artikel arbeiten wir praktisch mit JavaScript.

In JavaScript sind reguläre Ausdrücke ebenfalls Objekte. Sie werden üblicherweise zusammen mit APIs wie exec und test von RegExp sowie match, replace und search von String verwendet.

Reguläre Ausdrücke haben selten eine einzige, endgültige Lösung. Meist hängt die Wahl von der Toleranz gegenüber Unsicherheit ab, und dasselbe Problem lässt sich oft auf mehr als eine Art lösen.

Erstellen eines regulären Ausdrucks

Schreibweise als Literal

Das Muster steht zwischen zwei Schrägstrichen //.

/[0-9]/

RegExp

Der Konstruktor des RegExp-Objekts wird aufgerufen.

new RegExp("[0-9]")

Flags

FlagBeschreibung
gGlobale Suche
iGroß-/Kleinschreibung ignorieren
mMehrzeilige Suche

/pattern/flags oder new RegExp("pattern", "flags").

Häufig verwendete reguläre Ausdrücke

Handynummern abgleichen

Da ständig neue Nummernbereiche vergeben werden, muss das Muster nicht allzu streng sein.

Die Nummer beginnt mit 1, gefolgt von 10 weiteren Ziffern – insgesamt also eine 11-stellige Handynummer.

const PHONE_NUMBER_REGEXP = /^1\d{10}$/;

export const isPhoneNumber = (phoneNumber?: string) => {
  if (!phoneNumber) {
    return false;
  }
  return PHONE_NUMBER_REGEXP.test(phoneNumber);
};

Personalausweisnummern validieren

  1. Eine Personalausweisnummer hat 18 Stellen.
  2. Die ersten 6 Stellen sind der Regionscode, wobei die erste Ziffer zwischen 1 und 8 liegt.
  3. Die nächsten 8 Stellen bilden das Geburtsdatum.
  4. Die darauffolgenden 3 Stellen sind die Sequenznummer.
  5. Die letzte Stelle ist die Prüfziffer (eine Ziffer oder X).

Einfache Variante

/[1-8]\d{16}[0-9X]/i

Strenge Variante

RegexBeschreibung
[1-8]\d{5}Erste 6 Stellen
[1|2]\d{3}Jahr
[01]\dMonat
[0-3]\d{4}Tag + 3-stellige Sequenznummer
(\d|x)Letzte Stelle: Prüfziffer
const ID_CARD_REGEXP = /^[1-8]\d{5}[1-2]\d{3}[01]\d[0-3]\d{4}(\d|X)$/i;

export const isIDCard = (IDCard?: string) => {
  if (!IDCard) {
    return false;
  }
  return ID_CARD_REGEXP.test(IDCard);
};

E-Mail-Adressen abgleichen

Einfache Variante

/^\w+@\w+\.\w+/i

Bei einer Adresse wie aa.aa@aa.com schlägt das Muster fehl.

Strenge Variante

const EMAIL_NUMBER_REGEXP = /^(\w+\.)*\w+@(\w+\.)+[A-Za-z]+/i;

export const isEmail = (email?: string) => {
  if (!email) {
    return false;
  }
  return EMAIL_NUMBER_REGEXP.test(email);
};

IP-Adressen abgleichen

Einfache Variante

/(\d{1,3}\.){3}\d{1,3}/i

Strenge Variante

const IP_REGEXP =
  /^(((\d{1,2})|(1\d{2})|(2[0-4]\d)|(25[0-5]))\.){3}((\d{1,2})|(1\d{2})|(2[0-4]\d)|(25[0-5]))$/;

export const isIP = (IP?: string) => {
  if (!IP) {
    return false;
  }
  return IP_REGEXP.test(IP);
};

URLs abgleichen

Einfache Variante

/^https?:\/\/[-\w.]+(:\d+)?(\/([\w\/_.]*)?)?$/i

Strenge Variante

const URL_REGEXP =
  /^https?:\/\/(\w*:\w*@)?[-\w.]+(:\d+)?(\/([\w\/_.]*(\?\S+)?)?)?$/i;

export const isURL = (URL?: string) => {
  if (!URL) {
    return false;
  }
  return URL_REGEXP.test(URL);
};

Chinesische Schriftzeichen abgleichen

const CHINESE_REGEXP = /^[\u4e00-\u9fa5]*$/;

export const isOnlyChinese = (chinese?: string) => {
  if (!chinese) {
    return false;
  }
  return CHINESE_REGEXP.test(chinese);
};

Reguläre Ausdrücke für Einsteiger

Lerne systematisch die Kernkonzepte und die gängige Syntax regulärer Ausdrücke kennen – ausgehend vom grundlegenden Abgleichen und Verarbeiten von Text.

Wenn ich ein Problem mit regulären Ausdrücken lösen musste, habe ich früher meist nur kurz gesucht, eine Lösung übernommen und sie notdürftig angepasst.
Mit der Zeit ist mir aufgefallen, dass solche Lösungen zwar funktionieren, aber kein gutes Gefühl hinterlassen – und nach einer Weile hatte ich ohnehin alles wieder vergessen. Deshalb habe ich die Grundlagen in einer wiederverwendbaren Einführung zusammengefasst, um nicht immer wieder in dieselben Fallen zu tappen.

Der bekannte amerikanische Programmierer Jamie Zawinski hat einmal gesagt:

Wenn du ein Problem hast und denkst, es mit regulären Ausdrücken zu lösen, hast du jetzt zwei Probleme.

Reguläre Ausdrücke sind ein Werkzeug, das schwer zu beherrschen und richtig einzusetzen ist.

Wenn sie so schwierig sind, warum nicht einfach bei Bedarf nachschlagen und das Problem lösen? Warum also lernen?

Wer eine Technik nicht kennt, kommt bei einem Problem gar nicht erst auf die Idee, sie einzusetzen.

Was ist ein regulärer Ausdruck?

Laut Wikipedia:

Ein regulärer Ausdruck (englisch: Regular Expression, häufig abgekürzt als regex, regexp oder RE) ist ein Konzept der Informatik. Ein regulärer Ausdruck beschreibt mit einer einzigen Zeichenkette all die Zeichenketten, die einer bestimmten Syntaxregel entsprechen, und gleicht sie ab. In vielen Texteditoren wird ein regulärer Ausdruck verwendet, um Text zu suchen und zu ersetzen, der einem Muster entspricht.

Kurz gesagt: Ein regulärer Ausdruck ist eine Zeichenkette, mit der Text abgeglichen und verarbeitet wird.

Warum reguläre Ausdrücke verwenden?

Im Arbeitsalltag begegnet man regulären Ausdrücken häufig, etwa beim Abgleich von Dateiformaten.

Wie lernt man reguläre Ausdrücke?

Wer bei jeder Aufgabe nur nachschlägt und weitermacht, sobald es funktioniert, verliert auf Dauer mehr Zeit – und vergisst es schnell wieder.

Eine Stunde am Tag über eine Woche kostet insgesamt weniger Zeit und bleibt besser im Gedächtnis.

Anforderungen zerlegen

Zerlege die Anforderung in mehrere Teil-Anforderungen und prüfe, ob sie voneinander unabhängig sind.

Zum Beispiel eine URL:

Was ist eine URL

“protocol + domain name + port + path to the file + parameters + anchor”

Eine E-Mail-Adresse:

username + @ + domain name

Das ist auch die grundlegende Herangehensweise in der täglichen Softwareentwicklung.

Teil-Anforderungen analysieren

Jede Teil-Anforderung kann aus mehreren Zeichen (Zeichenklassen), mehreren Zeichenketten (Alternativen) und Häufigkeitsangaben (Quantifizierern) bestehen.

Regeln der Sprache

Schlag die Syntaxreferenz nach und schreibe den Ausdruck nach den Regeln der jeweiligen Sprache auf.

TDD

Verifiziere die Korrektheit des Ausdrucks mit TDD. Beim ersten Versuch schreibt man selten einen korrekten Ausdruck – beginne mit dem einfachsten Fall.

Rot bedeutet: der Test schlägt fehl.

Grün bedeutet: der Test ist erfolgreich.

Nach einem erfolgreichen Test kannst du refaktorieren und anschließend erneut sicherstellen, dass der Test besteht.

Wie verwendet man reguläre Ausdrücke?

Übe Zurückhaltung.

Ein Ausdruck, der auf einen Schlag alle Probleme löst, ist für andere nicht lesbar – er hat keine Wartbarkeit und kann praktisch nur neu geschrieben werden.

  1. Wenn sich ein Problem mit Zeichenketten lösen lässt, verwende Zeichenketten.

  2. Schreibe auf jeden Fall Kommentare.

  3. Wenn mehrere einfache reguläre Ausdrücke genügen, bestehe nicht auf einem einzigen komplexen Ausdruck.

Zeichen

Text abgleichen

"I love JavaScript!".match(/love/);

Mehrere Treffer abgleichen

Die meisten Regex-Engines geben standardmäßig nur den ersten Treffer zurück.

Mit dem g-Flag (global) gibt JavaScript ein Array mit allen Treffern zurück.

"I love love love JavaScript!".match(/love/g);

Groß- und Kleinschreibung ignorieren

Standardmäßig unterscheiden reguläre Ausdrücke zwischen Groß- und Kleinschreibung. Mit dem i-Flag zwingt JavaScript den Ausdruck, die Groß-/Kleinschreibung zu ignorieren.

"I love Love love JavaScript!".match(/love/gi);

Beliebiges Zeichen abgleichen

. gleicht ein beliebiges einzelnes Zeichen ab – auch Buchstaben und Ziffern.

Um einen tatsächlichen Punkt abzugleichen, musst du ihn mit \. maskieren.

"Z".match(/./); // [ 'Z', index: 0, input: 'Z', groups: undefined ]

Sonderzeichen abgleichen

Der Punkt (.) hat in regulären Ausdrücken eine besondere Bedeutung. Wer wirklich einen Punkt abgleichen möchte, muss ihn mit einem Backslash (\) maskieren.

"test.js".match(/\.js/);

Eine Gruppe von Zeichen

Eine Gruppe von Zeichen abgleichen

[] gleicht selbst kein Zeichen ab, sondern definiert lediglich eine Zeichenmenge. Eine Zeichenmenge ist eine ODER (OR)-Verknüpfung und keine UND (AND)-Verknüpfung.

[0123456789] gleicht jede Ziffer ab.

"Mop top".match(/[tm]op/gi);

Zeichenbereiche

Lege eine Zeichenmenge fest, von der genau eines der Zeichen übereinstimmen muss.

Reguläre Ausdrücke verwenden häufig Zeichenbereiche (0–9, a–z usw.). Zur Vereinfachung dient der Bindestrich -, der einen Zeichenbereich definiert.

  1. - ist nur innerhalb von [] ein Metazeichen; außerhalb einer Zeichenmenge ist es ein gewöhnliches Zeichen -.
  2. Das Endzeichen muss größer sein als das Anfangszeichen (z. B. ist [9-1] ungültig).

[A-Z] gleicht alle Großbuchstaben ab.

[a-z] gleicht alle Kleinbuchstaben ab.

[0-9] gleicht jede Ziffer ab.

[A-Za-z0-9] gleicht Buchstaben und Ziffern ab.

[0-9A-Fa-f] gleicht Hexadezimalfarben ab.

"test a string range".match(/[a-z]/g);

Ausschluss

Schließe die in der Zeichenmenge angegebenen Zeichen aus.

Verwende dafür das ^-Zeichen innerhalb der Zeichenmenge.

[^0-9]: gleicht alle Zeichen ab, die keine Ziffern sind.

"No numbers here?".match(/[^0-9]/g);

Metazeichen

Sie haben eine besondere Bedeutung und repräsentieren nicht das Zeichen selbst.

Metazeichen für Whitespace

Je nach Betriebssystem unterscheiden sich Zeilenumbruch und Wagenrücklauf; üblich ist \r\n.

MetazeichenBedeutung
[\b]Backspace (löscht ein Zeichen)
\fSeitenvorschub (Form Feed)
\nZeilenvorschub (Line Feed)
\rWagenrücklauf (Carriage Return)
\tTabulator
\vVertikaltabulator

Whitespace-Zeichen abgleichen

MetazeichenBedeutung
\s=[\f\n\r\t\v]ein beliebiges Whitespace-Zeichen
\S=[^\f\n\r\t\v]ein beliebiges Nicht-Whitespace-Zeichen

\s steht für space.

Es umfasst Leerzeichen, Tabulator \t, \v, \n, \f und \r – jedoch keinen Backspace.

\s enthält [\b] nicht, und \S schließt [\b] ebenfalls nicht aus.

Ziffern abgleichen

\d steht für digit.

MetazeichenBedeutung
\d = [0-9]eine beliebige Ziffer
\D = [^0-9]ein beliebiges Zeichen, das keine Ziffer ist
"123-123123-12312".match(/\d/g); // 数字
"123-123123-12312".match(/\D/g); // 非数字

Buchstaben, Ziffern und Unterstriche abgleichen

MetazeichenBedeutung
\w = [a-zA-Z0-9_]ein beliebiger Buchstabe, eine Ziffer oder ein Unterstrich _
\W = [^a-zA-Z0-9_]ein beliebiges Zeichen, das weder Buchstabe, Ziffer noch Unterstrich _ ist

\w steht für word.

Zahlenwerte in verschiedenen Basen

\x steht für hexadezimal; \x0A ist also Zeichen 10.

\0 steht für oktal; \011 ist also Zeichen 9.

Wiederholtes Abgleichen

Ein oder mehrere Zeichen abgleichen

+ = {1,}

"123-123123-12312".match(/\d+/g); //  [ '123', '123123', '12312' ]
"123-123123-12312".match(/\D+/g); //  [ '-', '-' ]

Null oder mehr Zeichen abgleichen

* = {0,1}

"100 10 1".match(/\d0*/g); // 100 10 1
"100 10 1".match(/\d0+/g); // 100 10

Null oder ein Zeichen abgleichen

? = {0, 1}

Das Zeichen ist optional – fast wie ein optionaler Operator?

"Should I write color or colour?".match(/colou?r/g); //  [ 'color', 'colour' ]

Eine exakte Anzahl von Wiederholungen abgleichen

\d{5} gleicht genau fünf Ziffern ab – nicht mehr. Ist auch das sechste Zeichen eine Ziffer, findet kein Treffer statt.

"test 12345 test".match(/\d{5}/g); // 12345

Einen Wiederholungsbereich abgleichen

{m, n}

\d{2,4} gleicht 2- bis 4-mal ab.

"Today is 5 22, 2022".match(/\d{2,4}/g); // 22 2022

Mindestens n Wiederholungen abgleichen

{n,}

Gleicht mindestens viermal ab.

"Today is 5 22, 2022".match(/\d{4,}/g); // 2022

Positionsabgleich

Wortgrenzen

\b steht für eine Wortgrenze, also die Position zwischen einem Wort und einem Leerzeichen.

Beim Abgleich mit regulären Ausdrücken gibt es zwei Konzepte: das Abgleichen von Zeichen und das Abgleichen von Positionen. \b gleicht eine Position ab.

"lucas lucas1 lucaslz".match(/\blucas\b/); // lucas

\B gleicht keine Wortgrenze ab (wo ein Leerzeichen steht, liegt eine Wortgrenze vor, also gibt es keinen Treffer).

"lucas lucas1 lucaslz".match(/\Blucas\B/); // null
"lucaslucas1lucaslz".match(/\Blucas\B/g); // lucas lucas  匹配第二个与第三个lucas

String-Grenzen

^ markiert den Anfang der Zeichenkette.

$ markiert das Ende der Zeichenkette.

"1本书，2本书".match(/^\d+/g); // 1
"1book,2book".match(/\w+$/g); // 2book
"1book,2book".match(/\w+$/g); // 2book
"1book，2book".match(/^\d\w+$/g); // null

Mehrzeilenmodus

JavaScript aktiviert den Mehrzeilenmodus mit dem /m-Flag.

Es beeinflusst das Verhalten von ^ und $.

`
第1本书正则
第2本书JavaScript
第3本书HTML
`.match(/\d+/gm); // 1,2,3
`
1book
2book
`.match(/^\d\w+$/gm); // '1book', '2book'

Teilausdrücke

Damit lassen sich Gruppen aus Zeichen oder Ausdrücken definieren.

() definiert einen Teilausdruck.

Mit Teilausdrücken gruppieren

Ohne Klammern wird o ein- oder mehrmals wiederholt.

"Googoogoo".match(/go+/gi); // 'Goo', 'goo', 'goo'

Mit Klammern wird go als Ganzes ein- oder mehrmals wiederholt.

"Googoogoo".match(/(go)+/gi); //  'Go', 'go', 'go'

Verschachtelte Teilausdrücke

Tiefe Verschachtelung macht den Ausdruck kaum lesbar.

/^(((\d{1,2})|(1\d{2})|(2[0-4]\d)|(25[0-5]))\.){3}((\d{1,2})|(1\d{2})|(2[0-4]\d)|(25[0-5]))$/;

Alternationsoperator

| steht für eine Alternation, also eine Auswahl zwischen Optionen.

"19902021".match(/(19|20)/g); // 19 20

Rückreferenzen

Ein Ausdruck, auf den innerhalb des regulären Ausdrucks verwiesen wird, heißt Rückreferenz.

Man kann sich eine Rückreferenz wie eine Variable vorstellen.

Abgleich mit Rückreferenzen

"This is a test test text.".match(/\s+(\w+)\s+\1/g); // ' test test'

Ersetzungsoperation

JavaScript verwendet bei Ersetzungen $.

const p = 'hello test@lucaslz.com';
const regex = /\w+[\w\.]*@[\w\,]+\.\w+)/;
p.replace(regex, '<a href="mailto:$1">$1</a>')

// result
hello <a href="mailto:test@lucaslz.com">test@lucaslz.com</a>

Lookaround

Manchmal dienen die Zeichen davor oder danach nur dazu, die Position eines Treffers festzulegen – sie sollen aber nicht im Ergebnis auftauchen.

Man spricht auch von einer Zero-Width Assertion.

Lookahead

(?=)

Um nur Ziffern abzugleichen, auf die 日 folgt, wird Lookahead verwendet.

"2022年5月29日".match(/\d+(?=日)/g); // 29

Negatives Lookahead

(?!)

Um Ziffern abzugleichen, auf die nicht 日 folgt.

"2022年5月29日".match(/\d+(?!日)/g); // '2022', '5', '2'  // 2后面也没有跟着日，所以会匹配上
"2022年5月29日".match(/\d+(?![\d+日])/g); //'2022', '5'

Lookbehind

(?<=)

Gleicht den Betrag auf dem Bon ab, ohne das Währungssymbol.

"2022年5月29日订单金额￥12".match(/(?<=￥)\d+/g); // 12

Negatives Lookbehind

(?<!)

Gleicht Ziffern ab, die nicht zum Bestellbetrag gehören.

"2022年5月29日订单金额￥12".match(/(?!=￥)\d+/g); // '2022', '5', '29', '12'

Gieriges Abgleichen

Reguläre Ausdrücke gleichen standardmäßig gierig ab: Sie erfassen so viele Zeichen wie möglich – je mehr, desto besser.

"ber beer beeer beeeer".match(/.*r/); // ber beer beeer beeeer

Lazy Matching

Gleicht so wenige Zeichen wie möglich ab und endet beim ersten Treffer.

"ber beer beeer beeeer".match(/.*?r/); // ber
